# 1. PROJECT

The product and website brand is:

**Wheelint**

Wheelint is a professional, industrial-grade automobile business management and billing software platform.

It is much broader than simple billing software.

The product is intended to cover the operational, financial, analytical, customer, inventory, sales, service, and management requirements of automobile businesses.

Wheelint should ultimately be positioned as a **complete automobile business management platform**, capable of serving:

* Independent workshops
* Authorised dealer workshops
* Multibrand workshops
* Automobile dealerships
* Dealer networks
* OEMs
* Enterprise automobile networks

The primary marketing focus should be:

**Workshops + dealerships first**

with:

**Enterprise ERP / OEM / dealer-network management**

presented as the higher-level enterprise capability.

Do not make Wheelint look like a small accounting application or a generic invoice generator.

It should feel like a serious professional platform used to operate an entire automobile business.

---

# 2. CRITICAL BRAND SEPARATION

Wheelint must be treated as its **own independent brand**.

Do NOT associate Wheelint publicly with Exillien Softech.

Do NOT mention that Wheelint is a rebrand, clone, successor, white-label product, or derivative of another product.

Do NOT use Exillien branding, Exillien logos, Exillien contact information, Exillien company descriptions, or Exillien references anywhere on the Wheelint website.

The existing AutoGenius material is being used internally as a **functional/product-information reference only**.

The website must present Wheelint as its own product and brand.

Think of AutoGenius and Wheelint as competitors from the perspective of the final website.

The fact that the underlying feature set is similar is an internal project detail and must never become website messaging.

# 3. REFERENCE IMAGE 1 — VISUAL / UI REFERENCE

The first uploaded image is a visual reference for the desired website design language.

It shows a premium sustainability SaaS landing page branded “Aetherfield”.

IMPORTANT:

**DO NOT RECREATE THIS WEBSITE.**

**DO NOT COPY ITS CONTENT.**

**DO NOT COPY ITS branding.**

**DO NOT COPY ITS exact layouts section-for-section.**

**DO NOT copy its illustrations, dashboard content, article content, testimonial wording, company identity, or exact visual compositions.**

Instead, extract the underlying design principles and reinterpret them specifically for Wheelint.

The reference is valuable because it avoids the generic corporate-SaaS look.

### Visual characteristics to learn from the reference:

* Extremely clean composition
* Large amounts of intentional whitespace
* Editorial-style typography
* Large, confident headlines
* Combination of serif display typography and clean sans-serif interface typography
* Strong visual hierarchy
* Minimal but premium UI elements
* Thin borders
* Carefully spaced cards
* Subtle background textures
* Soft gradients
* Pale blue and warm neutral sections
* Large product/interface visualizations
* Asymmetrical compositions
* Sections that feel editorial rather than like repetitive SaaS blocks
* Restrained use of buttons
* Strong use of typography as a design element
* Large visual moments separated by quiet whitespace
* Minimal navigation
* Premium but not “luxury brand” styling
* Modern, sophisticated, highly intentional layouts

The important takeaway is:

**Wheelint should feel designed, not templated.**

Avoid the common AI-generated SaaS aesthetic of:

* Huge generic gradient blobs
* Excessive rounded rectangles
* Constant floating cards
* Random abstract 3D objects
* Excessive glassmorphism
* Generic blue corporate dashboards
* Stock-photo-heavy layouts
* Repeating identical three-card sections
* Excessive shadows
* Overly colorful UI
* Huge amounts of text everywhere

Use the first image as a **design philosophy reference**, not a webpage template.

# 11. PRIMARY TARGET AUDIENCE

The website should immediately make sense to automobile businesses.

Primary audience:

### Independent workshops

Businesses that need billing, service operations, inventory, accounts, customer records and reporting.

### Authorised dealerships

Businesses managing workshop operations, vehicle sales, parts, customers, service, inventory and dealership workflows.

### Multibrand workshops

Businesses servicing multiple automobile brands and needing flexible management.

Secondary / enterprise audience:

### Dealer networks

Businesses or organisations managing multiple locations and dealerships.

### OEMs

Organisations needing enterprise-level visibility, reporting, monitoring and network management.

The website should not make the enterprise audience dominate the first impression.

The homepage should first communicate:

**“This is the platform that can run my automobile business.”**

Then progressively communicate:

**“It can also scale to networks and enterprise operations.”**

# 22. RESPONSIVE DESIGN

The entire website must be designed responsively from the beginning.

Do not create a desktop design and merely shrink it for mobile.

* Proper responsive typography
* Simplified layouts where necessary
* Touch-friendly controls
* Clean navigation
* Properly stacked product sections
* Readable dashboards
* Proper CTA placement
* No horizontal overflow
* No broken cards or tables
* Appropriate image cropping
* Mobile-friendly forms

The design philosophy of the reference should survive on mobile without simply becoming a compressed desktop page.
